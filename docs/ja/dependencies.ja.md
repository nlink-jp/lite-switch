# 依存関係

本書は、各サードパーティ依存関係を採用した理由を記録するものです（RULES.md §18 参照）。

## github.com/BurntSushi/toml

- **目的**: TOML 形式のシステム設定ファイル（`config.toml`）を解析する。
- **内製しない理由**: TOML の解析には単純ではない文法処理が必要であり、実績のあるライブラリを使うことでリスクを抑えられる。
- **ライセンス**: MIT

## gopkg.in/yaml.v3

- **目的**: YAML 形式のスイッチ定義ファイル（`switches.yaml`）を解析する。
- **スイッチに YAML を採用する理由**: スイッチファイルは利用者が直接扱う分類データ（タグと説明のペアのリスト）である。この用途では、YAML のリスト構文（`- tag: foo`）のほうが TOML の配列テーブル（`[[switches]]`）より読みやすく簡潔である。
- **内製しない理由**: TOML と同じ理由 — 文法の複雑さがライブラリの採用を正当化する。
- **ライセンス**: MIT および Apache 2.0
